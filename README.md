## The word

> defenestration

The act of throwing someone out of a window. Nobody guesses it; everybody
sees it. A formal, scholarly word for something gloriously undignified —
that clash is the joke, and the image (hands, a sash window, gravity) does
the rest.

## How it works

`main.ts` is a deterministic program that writes exactly that one word to
`/output/entry.txt` (14 bytes, no trailing newline). It checks the gate
locally first: UTF-8, 1–24 characters, exactly one word.

Run it locally (the grader sandbox writes to `/output`):

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
